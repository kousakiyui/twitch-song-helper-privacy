Privacy Policy — Twitch Song Helper Prepared: October 26, 2026. Publisher/support: kousakilol.

What the extension processes After you manually start listening, the extension reads the displayed chat in the selected Twitch tab. It processes public display names, message identifiers and song-request text. Accepted requests, song titles/artists, request/completion times, skipped/sung status, session counts, commands, preferences and repertoire/search caches are stored in your browser's extension storage. Ordinary chat messages are processed transiently; the extension keeps the last-message timestamp, not a general chat archive.

Network requests Twitch supplies the chat displayed in your tab. Song-request text is sent as a YouTube search query using temporary background tabs. The chosen channel ID is sent to StreamerSonglist to request its public repertoire and continuation pages. The extension does not operate a developer collection server and contains no developer analytics or advertising SDK. It does not sell data. These requests necessarily disclose your IP address and normal request/browser metadata to the destination services. Websites opened in tabs may use their existing browser sessions and cookies under their own policies. StreamerSonglist fetches explicitly omit credentials. The extension does not request the browser cookies permission, read passwords, or ask for an API key.

Local files and retention TXT/JSON exports are saved where your browser downloads files. JSON can include public requester names and session history; protect exported files and share them only as intended. Import reads the file you select locally; it is not uploaded to a developer server. Restore replaces current records and keeps one local pre-restore recovery copy. Records and preferences remain until you clear, replace or uninstall them; search results are reused for up to 24 hours but an expired cache entry is not necessarily physically removed immediately. Catalogue caches are cleared when the active channel changes after stopping. Turning off listening is not deletion. Clearing song history removes the selected channel's completed/skipped records, not pending songs, counts, caches or recovery copies. Uninstalling normally removes extension-local storage, but does not remove exported files; delete those separately. Browser profile backups may retain copies.

Permissions and control Listening starts manually and stays locked to the selected streamer until Stop. Site access is used only for supported features described above. Language detection uses browser language preferences locally; language is not sent to the publisher. There is no cloud synchronization or account created by this extension. For questions, use the publisher/support profile linked above. Policy changes should be published alongside a new extension release. This extension is independent of Twitch, YouTube and StreamerSonglist; their own privacy policies govern their services.
