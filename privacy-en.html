Privacy Policy — Twitch Song Helper

Last updated: October 30, 2026

Purpose

Twitch Song Helper helps streamers manage song requests from a selected Twitch channel's public chat. The extension starts monitoring after the user chooses to start it.

Information processed and stored locally

The extension processes public chat messages to identify song requests. It may store request text, public requester names, message IDs, song titles and artists, queue and history entries, timestamps, session counts, song corrections, local song lists, key markings and settings in the browser's extension storage.

Ordinary chat messages are processed to detect requests; the extension does not create a general archive of all chat messages. Public song-list and search data may be cached locally.

Twitch

In automatic mode, the extension attempts to connect to Twitch chat using an anonymous, read-only connection. It sends the selected channel ID and an anonymous nickname to Twitch. If necessary, it can read the selected channel's chat page instead. The extension does not ask for a Twitch password or use the cookies permission.

StreamerSonglist

The selected channel ID is sent to StreamerSonglist to retrieve the streamer's public song list. A copy may be stored locally for song-list matching. Songs added to the extension's local song list are not automatically uploaded to StreamerSonglist.

Apple iTunes and YouTube searches

When the extension searches for a song, it may send the song-request text directly to Apple iTunes Search or YouTube to obtain song title, artist or video suggestions.

The extension does not separately add the requester's name, Twitch message ID or channel ID to the iTunes song search. If a requester voluntarily includes a name, contact detail or other personal information in the song-request text itself, that information may be included in the search sent to the third-party service.

Apple, YouTube, Twitch and StreamerSonglist may receive the user's IP address and ordinary connection information when the browser connects to their services. Their own privacy policies apply.

Backups and retention

Song records and settings remain in local extension storage until the user deletes or replaces them, or removes the extension. The user can export and import JSON backups. Exported files may contain public requester names and song-request text, so users should store and share them carefully.

The extension does not automatically synchronize data to Google Drive. Users may choose where to store exported backup files themselves.

Data collection by the developer

The developer does not operate a server to collect extension user data. The extension does not include advertising or analytics SDKs. Information is processed for managing song requests and is sent to the third-party services described above when their functions are used.
