Privacy policy — Twitch Song Helper

Updated

2026-10-31. Publisher/support: kousakilol — https://www.twitch.tv/kousakilol

Purpose and local data

This extension manages song requests from public Twitch chat. It processes public display names, message IDs and request text. Accepted requests (including requests awaiting review), song titles/artists, queue/history, timestamps, session counts, commands, settings and repertoire/search caches are stored in browser extension storage. Ordinary messages are transiently processed; only the last-message timestamp is kept, not a general chat archive.

Twitch connections

After you manually start, automatic mode first attempts an anonymous, read-only WebSocket connection to irc-ws.chat.twitch.tv. The channel ID and a random anonymous nickname are sent, without an account token or API key. If it fails, a matching Twitch tab is read or a background chat-only tab is opened. You may manually choose direct or page capture. Silence is not treated as disconnection. Stop ends monitoring. Twitch tab sessions/cookies follow Twitch policies; the extension does not read passwords or use the cookies permission.

YouTube and StreamerSonglist

When YouTube candidates are needed or YouTube request mode is used, song-request text is sent directly to YouTube using background HTTPS search requests, with credentials omitted. Up to three candidates are kept; failures can be handled with manual search. No YouTube tab opens automatically in the normal search flow. Channel IDs are sent to StreamerSonglist to load public repertoire and continuation pages, with credentials omitted. These third-party services receive your IP address and normal connection metadata under their own policies. The extension operates no developer data-collection server and has no analytics or advertising SDK.

Control and retention

Data stays until you delete history, remove individual queue/review entries, replace data from backup, or uninstall. Cache and active catalogue state are cleared when switching channel after Stop; saved per-channel history/counts remain. JSON export includes song data, pending/approved states, sessions and preferences (theme, language, font, capture/request modes), but not running connections or repertoire/search caches. TXT and JSON exports may contain public requester names. Import replaces data after confirmation and keeps a local recovery snapshot.

Permissions

storage saves local state; scripting reads the selected Twitch page and retains compatibility with the earlier reader; alarms checks connection health and search timeouts; activeTab detects the active channel after a user action. Host access supports Twitch, YouTube, StreamerSonglist and iTunes. No remote code is evaluated, no data is sold, and no data is used for unrelated advertising or credit decisions.

Support

Version 1.1

Backups can be filtered by channel/completion date and split into files of up to 2 MB. Import defaults to merging: existing IDs and settings are retained and session counters use the larger value, not a sum. Importing stops monitoring and requires enough extension storage for a recovery snapshot. Partial split imports cannot start listening until every part is loaded. Capacity warnings and cache cleanup run locally; song records are not automatically deleted. Closing the management panel does not stop capture; use Stop to end it.

iTunes and local song list

The extension sends song-request text directly to Apple iTunes Search to suggest song titles and artists. Requester names, Twitch message IDs and channel IDs are not added to this search. If a requester includes personal information in the request text, it may be sent as part of the search. Apple receives your IP address and connection metadata. A local per-channel song list and pitch markings are stored on your device and included in JSON backups; the public song-list cache stays local. There is no automatic Google Drive sync. Gemini integration and artwork requests are not included.

YouTube request mode

In YouTube request mode, the extension searches for videos using the title or URL entered by a viewer. The local queue and playback history include requester, video title and link and may be included in JSON backups. Opening a video opens a YouTube tab and moves the item to playback history; this does not mean playback has finished. You can clear the current channel’s playback history.
