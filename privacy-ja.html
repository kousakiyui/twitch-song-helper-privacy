プライバシーポリシー — Twitch Song Helper

最終更新日：2026年10月30日

目的

Twitch Song Helper は、配信者が指定した Twitch チャンネルの 公開チャットに寄せられる楽曲リクエストを管理するための拡張機能です。 ユーザーが取得を開始した後に動作します。

処理および端末内に保存する情報

拡張機能は、楽曲リクエストを識別するために公開チャットメッセージを 処理します。リクエスト本文、公開されているリクエスト者名、 メッセージ ID、曲名、アーティスト名、キューと履歴、 タイムスタンプ、配信ごとの集計、修正情報、ローカル曲リスト、 キー設定および各種設定を、ブラウザーの拡張機能ストレージに 保存する場合があります。

一般のチャットメッセージもリクエストの識別のために処理しますが、 すべてのチャットを保存する履歴は作成しません。 公開曲リストや検索データを端末内に一時保存する場合があります。

Twitch

自動モードでは、まず匿名の読み取り専用接続で Twitch チャットに 接続を試みます。選択されたチャンネル ID と匿名のニックネームが Twitch に送信されます。必要に応じて、選択したチャンネルの チャットページを読み取ることもできます。Twitch のパスワードを 要求せず、cookies 権限も使用しません。

StreamerSonglist

配信者の公開曲リストを取得するため、選択されたチャンネル ID を StreamerSonglist に送信します。照合用にリストのコピーを端末内へ 保存する場合があります。拡張機能のローカル曲リストに追加した曲は、 StreamerSonglist に自動でアップロードされません。

Apple iTunes と YouTube の検索

曲を検索する際、曲名、アーティスト名または動画の候補を取得するため、 リクエスト本文を Apple iTunes Search または YouTube に 直接送信する場合があります。

iTunes の楽曲検索には、リクエスト者名、Twitch メッセージ ID、 チャンネル ID を別途追加しません。ただし、入力者がリクエスト本文に 氏名、連絡先などの個人情報を自ら入力した場合、その内容が検索文字列と 一緒に第三者サービスへ送信される可能性があります。

ブラウザーが Apple、YouTube、Twitch、StreamerSonglist に 接続する際、各サービスはユーザーの IP アドレスや通常の接続情報を 受け取る場合があります。各サービスのプライバシーポリシーが適用されます。

バックアップと保存期間

曲の記録と設定は、ユーザーが削除・置換するか、拡張機能を削除するまで、 ブラウザーの拡張機能ストレージに保存されます。ユーザーは JSON バックアップをエクスポートまたはインポートできます。 エクスポートしたファイルには公開リクエスト者名やリクエスト本文が 含まれる場合があるため、保管や共有にはご注意ください。

拡張機能が Google ドライブにデータを自動同期することはありません。 エクスポートしたバックアップの保存先はユーザー自身が選択できます。

開発者によるデータ収集

開発者は、拡張機能のユーザーデータを収集するサーバーを運営していません。 また、広告 SDK や分析 SDK も含まれていません。データは楽曲リクエストの 管理に使用され、上記の第三者サービスの機能を使用する場合に、 本ポリシーに記載した情報が送信されます。
