プライバシーポリシー — Twitch リクエスト管理

更新日

2026-10-31。公開者・サポート：kousakilol — https://www.twitch.tv/kousakilol

目的とローカルデータ

Twitch 公開チャットの曲リクエストを管理します。公開表示名、メッセージ ID、リクエスト文を処理し、確認待ちを含む曲情報、キュー、履歴、時刻、セッション別回数、コマンド、設定、曲リストと検索のキャッシュをブラウザー内に保存します。通常の発言は一時的に処理し、最終受信時刻のみ保持します。一般チャットの履歴は保存しません。

Twitch 接続

手動開始後、自動モードは irc-ws.chat.twitch.tv に匿名・読み取り専用の WebSocket で接続し、チャンネル ID とランダムな匿名ニックネームを送信します。アカウントトークンや API キーは使いません。失敗時は該当 Twitch ページを取得し、必要に応じチャット専用のバックグラウンドタブを開きます。取得元は手動でも選べます。発言がないだけでは切断とみなしません。停止で監視を終了します。ページの既存セッションや Cookie は Twitch のポリシーに従います。パスワードを取得せず、cookies 権限を要求しません。

YouTube と StreamerSonglist

YouTube の候補が必要な場合、または YouTube リクエストモードを使う場合、リクエスト文は認証情報を省略したバックグラウンド HTTPS 検索で YouTube に直接送られ、候補を最大3件保存します。失敗時は手動検索できます。通常の検索は YouTube タブを自動で開きません。チャンネル ID は StreamerSonglist に送信し、認証情報を省略して公開曲リストと続きのページを取得します。各サービスは独自のポリシーに従い IP アドレスなどの接続情報を受け取ります。開発者のデータ収集サーバー、解析・広告 SDK はありません。

保存と管理

履歴やキュー・確認待ち項目の削除、バックアップによる置換、アンインストールが可能です。停止後のチャンネル変更で現在の曲リストと検索キャッシュを消去し、チャンネル別履歴や回数は保持します。JSON バックアップには曲、確認状態、セッション、テーマ・言語・文字サイズ・接続・受付モードを含み、実行中の接続や曲リスト・検索キャッシュは含みません。復元は確認後に実行し、復元前のローカルコピーを保存します。TXT／JSON には公開表示名が含まれる場合があります。

権限

storage はローカル保存、scripting は指定 Twitch ページの取得と従来方式との互換性、alarms は接続確認と検索タイムアウト、activeTab は利用者操作後のチャンネル検出に使います。サイト権限は Twitch、YouTube、StreamerSonglist、iTunes 用です。リモートコードを実行せず、データの販売、無関係な広告や信用判断への利用はしません。

サポート

https://www.twitch.tv/kousakilol。Twitch、YouTube、StreamerSonglist とは無関係の独立プロジェクトです。

バージョン1.1

バックアップはチャンネルと完了日で絞り込み、各2MB以下のファイルに分割できます。読み込みは標準で結合し、既存IDと設定を保持、配信別カウントは加算せず大きい値を採用します。読み込み時は取得を停止し、復元前コピーを保存する拡張機能内の空き容量が必要です。分割ファイルをすべて読み込むまで取得を開始できません。容量確認とキャッシュ整理はローカルで行い、曲を自動削除しません。管理パネルを閉じても取得は続きます。終了には停止ボタンを使ってください。

iTunes とローカル曲リスト

曲名とアーティストの候補を探すため、リクエスト文字列を Apple iTunes Search に直接送信します。リクエスト者名、Twitch メッセージ ID、チャンネル ID は追加しません。入力者が文字列に個人情報を含めた場合は、その情報も送信される可能性があります。Apple は IP アドレスと接続情報を受け取ります。チャンネル別のローカル曲リストとキー設定は端末内に保存し JSON バックアップに含めます。公開曲リストのキャッシュは端末内に残ります。Google Drive への自動同期、Gemini 連携、ジャケット画像の取得はありません。

YouTube リクエストモード

YouTube リクエストモードでは、視聴者が入力したタイトルまたは URL で動画を検索します。再生待ちと再生履歴、リクエスト者、動画タイトルとリンクはローカルに保存され、JSON バックアップに含めることができます。動画を開くと YouTube タブが開き、履歴に移動しますが、再生が完了したことを意味しません。現在のチャンネルの再生履歴は削除できます。
