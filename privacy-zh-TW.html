隱私權政策 — twitch實況抓歌

更新日期

2026-10-31。發布者／支援：kousakilol — https://www.twitch.tv/kousakilol

用途與本機資料

本插件管理 Twitch 公開聊天室的點歌，處理公開顯示名稱、訊息 ID 與點歌文字。收錄的請求（含待確認）、歌名／演出者、排隊與歷史、時間、本場計數、指令、設定及歌單／搜尋快取儲存在瀏覽器擴充功能儲存空間。一般聊天僅暫時處理，保留最後收到訊息的時間，不建立一般聊天紀錄。

Twitch 連線

手動開始後，自動模式優先匿名唯讀連接 irc-ws.chat.twitch.tv WebSocket，傳送頻道 ID 與隨機匿名暱稱，不使用帳號權杖或 API 金鑰。失敗時讀取對應 Twitch 分頁，必要時自動開啟純聊天室背景分頁。可手動指定來源；安靜不視為斷線。停止即結束監聽。網頁既有登入與 Cookie 依 Twitch 政策運作；插件不讀密碼、不要求 cookies 權限。

YouTube 與 StreamerSonglist

需要 YouTube 候選或使用 YouTube 點播模式時，點歌文字透過背景 HTTPS 請求直接送到 YouTube 搜尋，省略憑證，保留最多三筆候選；失敗時可手動搜尋。正常搜尋不自動開 YouTube 分頁。頻道 ID 送到 StreamerSonglist 讀取公開歌單與續頁，同樣省略憑證。第三方服務依其政策接收 IP 與一般連線資訊。本插件沒有開發者資料收集伺服器、分析或廣告 SDK。

保存與控制

可清除歷史、刪除排隊或待確認項目、匯入備份取代資料，或解除安裝移除本機資料。停止後切換頻道會清除活躍歌單與搜尋快取，保留依頻道區分的歷史及計數。JSON 備份包含歌曲、待確認／已放行及超額暫存狀態、場次及主題／語言／字體／來源／收歌模式，不包含執行中的連線或歌單／搜尋快取。可按頻道及日期匯出舊紀錄，較大備份會分檔。匯入可選合併或取代，需確認並另存插件內還原前快照；合併不累加相同場次計數。容量提示與快取清理均在本機執行。匯出 TXT／JSON 可能包含公開點歌者名稱，請自行妥善保管。

權限

storage 保存本機資料；scripting 讀取指定 Twitch 網頁並保留舊版讀取相容程式；alarms 檢查連線與搜尋逾時；activeTab 在使用者操作後辨識頻道。網站權限用於 Twitch、YouTube、StreamerSonglist 與 iTunes。不執行遠端程式碼、不販售資料、不用於無關廣告或信用判斷。

支援

https://www.twitch.tv/kousakilol。本插件為獨立專案，與 Twitch、YouTube、StreamerSonglist 無隸屬關係。

iTunes 與本機歌單

為提供歌名與歌手候選，插件會將觀眾輸入的點歌文字直接傳送至 Apple iTunes Search。若輸入者自行在文字中輸入姓名或其他個人資訊，該資訊可能隨查詢傳送；插件不會另外附上點歌者名稱、Twitch 訊息 ID 或頻道 ID。Apple 可能收到 IP 位址及連線資訊。各頻道本機歌單與 Key 標記保存在本機並包含於 JSON 備份，公開歌單快取保存在本機。本版沒有 Google 雲端自動同步、Gemini 功能或封面圖片搜尋。

YouTube 點播模式

切換至 YouTube 點播後，插件以觀眾輸入的標題或網址搜尋影片。待播及已播放紀錄、點播者、影片標題與連結會保存在本機，並可隨 JSON 備份匯出。按下開啟影片後，插件開啟 YouTube 分頁並將該項目移到已播放；這不代表影片已播放完畢。可清除目前頻道的已播放紀錄。
